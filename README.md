
# Student Management System (CLI)

This is a CLI-based Java CRUD application.

## Features
- Add Student
- View Students
- Update Student
- Delete Student

## Technologies Used
- Java
- ArrayList
- Scanner
- Loops & Conditionals

## Project Files
- Student.java
- studentService.java
- StudentCLI.java
 -Run CLI:
java -jar StudentManagementCLI.jar
